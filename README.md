# NextGen Summit 2026 Digital Program

Mobile-friendly event program for October 19–20, 2026: Monday and Tuesday schedules, campus map, and ministry resources.

## Editing

- `content.js`: schedule times, locations, leaders, five-minute spotlights, and resource links.
- `index.html`: page sections and campus location descriptions.
- `styles.css`: responsive layout and theme artwork crop.
- `app.js`: schedule day buttons and resource cards.
- `assets/campus-map.png`: current map, including Lincoln Room, Clark Room, and ISM Office.
- `assets/summit-theme.png`: supplied Good Shepherds Inc. theme artwork.

GitHub Pages publishes from `main`, repository root. Changes committed to that branch deploy automatically. No build step or external JavaScript dependencies are required. For local preview, open `index.html` directly or serve the folder using a static HTTP server.

## Organizer-confirmed details

Lincoln Room is in the Activities Center. Clark Room is in Schneider Center. Meal locations use Dining Room. Evelyn Girard leads BGMC; Pastor Joel Labertew's Tuesday devotional starts at 9:35 AM. The ISM Resource List link is included in Resources.
